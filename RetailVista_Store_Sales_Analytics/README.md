# RetailVista | Store Sales & Customer Insights

## Project Overview
An Excel-based store sales dashboard for analyzing 2022 order activity, customer demographics, order status, sales channels and state-level performance.

## Tools & Technologies
Microsoft Excel; Pivot Tables; Pivot Charts; Slicers; Conditional Formatting; Excel formulas

## Dashboard Highlights
Order status analysis; sales by gender; top five states; age-group and gender breakdowns; monthly orders vs sales; sales channel analysis.

## How to Use
1. Download or clone this repository.
2. Open the workbook in the relevant desktop application.
3. If prompted, enable editing or allow the packaged data connection.
4. Explore the dashboard and its available filters.
